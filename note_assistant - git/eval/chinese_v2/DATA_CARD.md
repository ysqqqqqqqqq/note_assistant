# 中文合成笔记检索集 v2

36篇虚构产品规范/流程/历史文档，72道问题，开发集36题和锁定测试集36题；按主题家族分离，每集6个主题。所有数值为虚构，不能当作真实产品规格。

每个主题包含直接事实、同义表达、否定、操作流程、跨版本双来源、无答案各一题。相关性等级2表示直接证据，未列来源为0；参考答案仅用于人工审查，不输入检索或模型。共12道无答案题。

过滤条件由评测输入提供，不代表系统能从自然语言自动提取metadata。语料可在索引阶段使用，但调参仅使用dev.json；test.json在选定配置后运行。manifest.json记录冻结时的SHA256。

这是同一作者生成的规则性合成集，题型和措辞存在偏差，不能替代真实笔记或人工盲评。不会调用生成LLM，不能据此声称faithfulness/answer relevance已评测。跨版本题需要两个来源都召回，报告Recall和完整证据召回率。

初稿v1仅用于结构审计，未进行模型评测；因提供了主题过滤使候选过少，在评分前另建v2。v2普通题仅过滤version=v2（24篇候选），跨版本题无过滤（36篇候选）。topic不输入检索过滤。
