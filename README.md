# Note Assistant

Note Assistant 是一个独立开发的笔记智能批注项目。它在浏览器中管理笔记和知识库，通过本地 BM25 检索为 AI 释义提供可追溯的原文依据，也支持录音转写、文本降噪和手动批注。网页由轻量本地服务提供；调用文本模型或语音识别时，由用户自行配置第三方 API。

## 功能

- **笔记与批注**：编辑笔记，自动提取专业术语和关键句，流式生成释义；也可手动添加批注。
- **浏览器知识库**：上传 TXT、MD 或 CSV，按原文片段建立索引，使用 BM25 检索；首次检索无可靠证据时可选择模型查询改写。批注展示可核对的来源，未命中时明确提示。
- **语音输入**：麦克风录音或上传音频，分段转写并保留可编辑的原始转写稿；文本降噪和生成批注由用户按需触发。
- **本地管理**：使用 IndexedDB 保存笔记历史与知识库，支持知识库 JSON 备份、PNG/Word 导出、中英双语界面和 5 种主题色。

## 运行

需要 Python 3.10+。在仓库根目录使用 PowerShell：

```powershell
cd "note_assistant - git"
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python server.py
```

打开 http://127.0.0.1:5000/ ，运行期间保持终端开启。Windows 用户完成依赖安装后，也可双击仓库根目录的 `启动笔记助手.cmd`；它会启动服务，或打开已运行的页面。请通过 localhost 或 HTTPS 访问，以便使用麦克风功能；不要直接用 `file://` 打开 `index.html`。

## 知识库与批注

1. 在“知识库”中上传 TXT、MD 或 CSV，再用“检索测试”核对命中的原文片段。文档和分块保存在当前浏览器的 IndexedDB 中。
2. 在设置中开启“使用浏览器知识库”。生成批注时，页面先用 BM25 搜索本地片段；没有可靠命中时会明确提示“无本地证据”，不会把模型回答冒充知识库来源。
3. 可选“查询改写”仅在首次检索未命中时调用已配置的文本模型，生成最多三个检索问句后再次搜索。改写失败或仍未命中时保留原始检索结果。此功能会向模型服务商发送查询文本，可能产生费用。

知识库面板支持 JSON 备份导出和导入；备份不包含笔记历史或 API 密钥。浏览器存储与访问地址绑定，更换浏览器或端口、清除站点数据后不会自动迁移，建议定期导出备份。索引在浏览器内存中构建，适合个人规模的知识库，不适合大量文档。

## 录音转文字

页面右上角的“🎙 录音”可打开语音输入面板，使用麦克风录音或上传已有音频。录音可开始、暂停/继续、完成或取消；完成后可试听，再手动点“转为文字”。原始转写显示在独立的可编辑文本框中，不会自动覆盖正文或做文本降噪。检查完成后点“追加到笔记正文”，再按需使用“文本降噪”“生成批注”和“保存笔记”。如果正文已有内容，追加前会确认。

转写使用设置页中独立的“语音识别”API 配置（Base URL、模型名、Key），与文本模型的配置互不覆盖。接口需兼容 multipart `/audio/transcriptions`。例如选择智谱时，可填写其 API 基础地址和 `glm-asr-2512`；也可选择其他兼容服务。音频会发送至所配置的服务商，可能产生费用；音频不会交给文本降噪模型。ASR 返回的中文和英文技术词原样显示，不额外翻译。

音频会切为不超过约 27 秒的 WAV 片段，按顺序发送；具体时长和大小限制仍取决于服务商。某段失败或取消后，已转写片段保留，可用“重新转写”继续；未补齐全部片段前不能追加不完整笔记。录音最长 2 小时；上传文件上限 80 MB / 90 分钟，且需要浏览器能解码。临时音频放在浏览器 IndexedDB，取消、删除或把完整转写追加进正文后删除；页面关闭时尝试删除，异常关闭遗留的临时音频会在超过 12 小时后、下次打开页面时清理。原始音频默认不长期保存，清空站点数据也会删除它。

需要支持 AudioWorklet 与麦克风 API 的现代浏览器，并通过 localhost 或 HTTPS 打开页面。请在浏览器允许麦克风权限；没有麦克风、设备被占用、网络中断或语音服务拒绝时，页面会显示可读的错误并保留可重试的音频。本文所述分段和异常路径经过模拟测试，尚未用真实麦克风和真实付费 ASR 服务做端到端实测。

## API 配置

模型批注及可选查询改写使用设置页中的兼容 Chat Completions 的 API 地址、模型名和 Key。语音转写使用独立的 ASR 配置。两者可分别保存多个配置，并用 6 位数字密码加密；使用前需解锁。解锁后的 Key 仅在当前页面内存中使用，刷新或锁定后需重新解锁。忘记密码无法恢复；清理站点数据会删除加密配置。6 位数字密码的离线抗猜测能力有限，不应视为高强度防护。

日常使用直接在页面设置中配置 API，不需要填写 `.env`。运行可选的本机检索实验或评测脚本时，可将应用目录中的 `.env.example` 复制为 `.env` 并自行填写凭据；`.env` 不应提交。BGE 实验配置见 `.env.bge-*.example`，模型标识可替换为本地模型目录。

“测试连接”会发送一条简短消息到服务商，不发送笔记，但可能产生费用。模型批注会发送对应笔记内容，查询改写会发送查询文本。遇到 429 时按服务商响应进行有限重试；额度耗尽仍需到服务商控制台处理。

## 测试

在应用目录执行：

```powershell
node --test tests/*.test.cjs
python -B -m unittest discover -s tests
```

中文合成数据集位于 `eval/chinese_v2`，包含 36 篇虚构文档和 72 道问题。浏览器 BM25 的评估是探索性回归检查，不能代表真实用户问题的准确率。引用编号标识检索来源，不保证模型回答的每句话都得到事实支持。

其他检索实验与局限见 `docs/EVALUATION.md`、`CHINESE_EVALUATION.md` 和 `ROUND6_EVALUATION.md`。其中的 BGE 混合检索/重排属于可选本机实验，**不是页面默认检索方式**；页面默认使用 BM25，不需要下载模型权重。复现实验需要自行获取 `BAAI/bge-small-zh-v1.5` 和 `BAAI/bge-reranker-base`，权重不随仓库提供。
