# Note Assistant

浏览器知识库驱动的笔记批注工具。笔记编辑、手工批注、历史记录、PNG/Word 导出、中英切换和 API 配置仍保留。当前页面只有一个知识库：当前浏览器中的 IndexedDB，不再要求启动本机检索服务或下载向量模型。

## 运行

已完成下方首次安装后，也可以双击外层文件夹里的 `启动笔记助手.cmd`；启动后请保持命令窗口开启。若服务已经运行，快捷入口会直接打开网页，不会重复启动。

需要 Python 3.10+。在 PowerShell 中进入应用目录并启动网页服务：

```powershell
cd "note_assistant - git"
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python server.py
```

打开 http://127.0.0.1:5000/ 。运行期间请保持终端开启。若此前已打开页面，请先复制尚未保存的笔记，再刷新页面。

## 知识库与三个动作

1. 在“知识库”中上传 TXT、MD 或 CSV。文档在当前浏览器保存，不会上传到本机 Flask 数据库。上传后可直接用“检索测试”核对命中的原文片段。
2. 在设置中打开“使用浏览器知识库”，生成批注时先用浏览器端 BM25 检索。关闭时不查知识库。检索无可靠命中时，页面会明确提示没有本地证据；模型的常识回答不会伪装成知识库检索结果。
3. 可在该开关下打开“查询改写”。只有原问题没有检索命中时，才用已配置的模型改写最多三个检索问句，并再次搜索**同一个浏览器知识库**。改写服务不可用、限流或仍无命中时，保持“无本地证据”，不会假造来源。查询改写会把问题发送给所配置的模型服务商，可能产生费用。

知识库面板提供 JSON 备份导出和导入。导入同名文档会覆盖对应浏览器文档，不影响其他文档；操作前页面会请求确认。备份不包含笔记历史和 API 密钥。浏览器数据与 `127.0.0.1:5000` 这个站点地址绑定；更换浏览器或端口、清理站点数据后不会自动保留，请定期导出备份。浏览器小型知识库采用全量内存索引，不适合大规模文档。

## 录音转文字

页面右上角的“🎙 录音”可打开语音输入面板，使用麦克风录音或上传已有音频。录音可开始、暂停/继续、完成或取消；完成后可试听，再手动点“转为文字”。原始转写显示在独立的可编辑文本框中，不会自动覆盖正文或做文本降噪。检查完成后点“追加到笔记正文”，再用现有的“文本降噪”“生成批注”“保存笔记”。如果正文已有内容，追加前会确认。

转写使用设置页中独立的“语音识别”API 配置（Base URL、模型名、Key），与文本模型的配置互不覆盖。接口需兼容 multipart `/audio/transcriptions`。例如选择智谱时，可填写其 API 基础地址和 `glm-asr-2512`；也可选择其他兼容服务。音频会发送至所配置的服务商，可能产生费用；音频不会交给文本降噪模型。ASR 返回的中文和英文技术词原样显示，不额外翻译。

音频会切为不超过约 27 秒的 WAV 片段，按顺序发送；具体时长和大小限制仍取决于服务商。某段失败或取消后，已转写片段保留，可用“重新转写”继续；未补齐全部片段前不能追加不完整笔记。录音最长 2 小时；上传文件上限 80 MB / 90 分钟，且需要浏览器能解码。临时音频放在浏览器 IndexedDB，取消、删除或把完整转写追加进正文后删除；页面关闭时尝试删除，异常关闭遗留的临时音频会在超过 12 小时后、下次打开页面时清理。原始音频默认不长期保存，清空站点数据也会删除它。

需要支持 AudioWorklet 与麦克风 API 的现代浏览器，并通过 localhost 或 HTTPS 打开页面。请在浏览器允许麦克风权限；没有麦克风、设备被占用、网络中断或语音服务拒绝时，页面会显示可读的错误并保留可重试的音频。本文所述分段和异常路径经过模拟测试，尚未用真实麦克风和真实付费 ASR 服务做端到端实测。

## API 配置

模型批注及可选查询改写使用设置页里填写的兼容 Chat Completions 的 API 地址、模型名和 Key。可以新增多个配置，并分别用 6 位数字密码加密保存；使用前需解锁。Key 不以明文存入普通设置，解锁后的 Key 仅在当前页面内存中使用，刷新或锁定后需重新解锁。忘记密码无法恢复；清理站点数据会删除加密配置。6 位数字密码只有有限的离线抗猜测能力，请勿把它理解为高强度防护。

默认浏览器版在页面设置中分别配置文本模型和语音识别模型，不需要填写 `.env`。可选的旧后端/评测脚本才使用环境变量：需要时在应用目录将 `.env.example` 复制为 `.env`，自行填写凭据；`.env` 不应提交。可选的本机 BGE 检索实验另有 `.env.bge-*.example` 模板，可把模型标识改为自己的本地目录。

“测试连接”会发送一条简短消息到服务商，不发送笔记，但可能产生费用。模型批注会发送对应笔记内容，查询改写会发送查询文本。遇到 429 时按服务商响应进行有限重试；额度耗尽仍需到服务商控制台处理。

## 旧本机知识库数据

以前版本的 `rag.sqlite3` 保留在原位置，本次升级**不会删除或自动迁移**它。当前页面不会读取这份数据库；如需使用其中的资料，请找到原始文件，在新版知识库重新上传。不要把“当前浏览器知识库为空”理解为旧数据已被清除。原后端代码保留用于既有测试和回退，但默认 `python server.py` 只提供网页与静态资源，不提供 `/kb/*`、`/rag/*` 接口。

## 测试

在应用目录执行：

```powershell
node --test tests/*.test.cjs
python -B -m unittest discover -s tests
```

中文合成数据集位于 `eval/chinese_v2`。浏览器 BM25 的评估是探索性回归检查，不是新盲测，也不能代表真实用户问题的准确率。引用编号只说明来自哪个检索片段，不保证模型回答的每句话都得到事实支持。

项目历史实验和本机混合检索的资料见 `docs/EVALUATION.md`、`ROUND6_EVALUATION.md`、`CHINESE_EVALUATION.md`；其中的本机检索配置与指标不代表当前默认浏览器版的运行方式。默认浏览器版不需要本地模型。可选旧评测需要 `BAAI/bge-small-zh-v1.5` 和 `BAAI/bge-reranker-base`，请从模型发布方自行获取，或在配置/命令中填写已下载的本地模型目录；模型权重不会随 GitHub 代码提供。
